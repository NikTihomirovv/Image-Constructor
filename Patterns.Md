### Описание всех паттернов для VK и Telegram
### Базовые параметры (общие для всех паттернов)
### Размер холста: 1080 × 1350 px (вертикальный формат)

### Все паттерны доступны для обеих платформ: VK и TG

### ПАТТЕРН 1: "Текст + Фоновое изображение" (vk_static_pattern_1 / tg_static_pattern_1)
    Структура: Сверху текстовый блок, снизу фоновое изображение.

    Элементы:
        IMAGE_1: Фоновое изображение, размер 1080×900, позиция (0, 450), z-index: 1
        TEXT_1: Текст, размер 980×400, позиция (50, 25), z-index: 1

    Обязательные параметры:
        img_1 (string): путь к изображению (JPG, PNG, SVG) или base64 строка
        text_1 (string): текст для отображения (поддерживает \n для переноса)

    Для чего использовать: 
        Посты с кратким описанием товара/услуги, анонсы мероприятий, рекламные посты с ярким изображением и кратким текстом, новостные посты.

### ПАТТЕРН 2: "Текст + Линия + Фоновое изображение" (vk_static_pattern_2 / tg_static_pattern_2)
    Структура: Текст с декоративной линией слева, снизу фоновое изображение.

    Элементы:
        IMAGE_1: Фоновое изображение, размер 1080×900, позиция (0, 450), z-index: 1
        IMAGE_2: Декоративная линия, размер 5×400, позиция (25, 25), z-index: 1
        TEXT_1: Текст, размер 980×400, позиция (50, 25), z-index: 1

    Обязательные параметры:
        img_1 (string): путь к фоновому изображению (JPG, PNG, SVG) или base64
        img_2 (string): путь к изображению линии (рекомендуется SVG) или base64
        text_1 (string): текст для отображения

    Для чего использовать: 
        Посты с цитатами, важные объявления, корпоративные новости с акцентом на текст, посты в стиле "важно".

### ПАТТЕРН 3: "Полноэкранный фон + Текст + Градиент + Указатель для свайпа" (3 вариации)
    Вариант FIRST (vk_static_pattern_3_first / tg_static_pattern_3_first)
        Структура: Полноэкранный фон, сверху заголовок и основной текст на градиентной подложке, внизу указатель для свайпа.

        Элементы:
            IMAGE_1: Фоновое изображение, размер 1080×1350, позиция (0, 0), z-index: 1
            IMAGE_2: Градиент, размер 1080×450, позиция (0, 900), z-index: 2
            IMAGE_3: Декоративная линия, размер 800×1, позиция (140, 1300), z-index: 3
            IMAGE_4: Стрелка-указатель, размер 65×65, позиция (657, 1240), z-index: 3
            TEXT_1: Заголовок, размер 980×200, позиция (50, 636), z-index: 3
            TEXT_2: Основной текст, размер 980×400, позиция (50, 836), z-index: 3
            TEXT_3: Текст указателя для свайпа, размер 300×30, позиция (357, 1250), z-index: 3

        Обязательные параметры:
            img_1 (string): путь к фоновому изображению 1080×1350 (JPG, PNG, SVG) или base64
            img_2 (string): путь к градиенту (рекомендуется SVG) или base64
            img_3 (string): путь к линии (рекомендуется SVG) или base64
            img_4 (string): путь к стрелке-указателю (рекомендуется SVG) или base64
            text_1 (string): заголовок
            text_2 (string): основной текст
            text_3 (string): текст указателя (например, "ЛИСТАЙ ДАЛЕЕ" или "СМОТРИ ДАЛЬШЕ")

        Для чего использовать: 
            Имиджевые посты с полноэкранной графикой, рекламные объявления с призывом к свайпу, статьи и лонгриды с ярким оформлением, карусельные посты.

    Вариант SECOND (vk_static_pattern_3_second / tg_static_pattern_3_second)
        Структура: Без отдельного заголовка - сразу большой блок текста.

        Элементы:
            IMAGE_1: Фоновое изображение, размер 1080×1350, позиция (0, 0), z-index: 1
            IMAGE_2: Градиент, размер 1080×450, позиция (0, 900), z-index: 2
            IMAGE_3: Декоративная линия, размер 800×1, позиция (140, 1300), z-index: 3
            IMAGE_4: Стрелка-указатель, размер 65×65, позиция (657, 1240), z-index: 3
            TEXT_1: Основной текст, размер 980×600, позиция (50, 536), z-index: 1
            TEXT_2: Текст указателя для свайпа, размер 300×30, позиция (357, 1250), z-index: 3

        Обязательные параметры:
            img_1 (string): путь к фоновому изображению 1080×1350 (JPG, PNG, SVG) или base64
            img_2 (string): путь к градиенту (рекомендуется SVG) или base64
            img_3 (string): путь к линии (рекомендуется SVG) или base64
            img_4 (string): путь к стрелке-указателю (рекомендуется SVG) или base64
            text_1 (string): основной текст
            text_2 (string): текст указателя (например, "ЛИСТАЙ ДАЛЕЕ" или "ДАЛЬШЕ →")

        Для чего использовать: 
            Посты с длинным текстом без заголовка, объявления с подробным описанием, отзывы и кейсы с призывом к свайпу.

    Вариант THIRD (vk_static_pattern_3_third / tg_static_pattern_3_third)
        Структура: Упрощенная версия без указателя и стрелки.

        Элементы:
            IMAGE_1: Фоновое изображение, размер 1080×1350, позиция (0, 0), z-index: 1
            IMAGE_2: Градиент, размер 1080×450, позиция (0, 900), z-index: 2
            IMAGE_3: Декоративная линия, размер 800×1, позиция (140, 1300), z-index: 3
            TEXT_1: Основной текст, размер 980×600, позиция (50, 536), z-index: 1

        Обязательные параметры:
            img_1 (string): путь к фоновому изображению 1080×1350 (JPG, PNG, SVG) или base64
            img_2 (string): путь к градиенту (рекомендуется SVG) или base64
            img_3 (string): путь к линии (рекомендуется SVG) или base64
            text_1 (string): основной текст

        Для чего использовать:
            Информационные посты без призыва к действию, поздравления и объявления, цитаты и вдохновляющие посты.

            TEXT_2: Основной текст, размер 980×500, позиция (50, 700), z-index: 3
            TEXT_3: Логотип/имя, размер 500×50, позиция (50, 1275), z-index: 3

### Общие требования к параметрам
    Форматы изображений:
    JPG, PNG, SVG (поддерживаются все форматы)

    Для декоративных элементов (линии, стрелки, градиенты) рекомендуется использовать SVG для лучшего качества

    Base64 поддерживается для всех форматов
    Форматы текста:
        Строки с поддержкой символа \n для переноса строк
        Автоматический перенос слов, если текст не помещается по ширине

    Структура запроса:

    json
    {
    "name": "Название паттерна",
    "platform_name": "vk" или "tg",
    "pattern_name": "имя_паттерна",
    "pattern_elements": {
        "img_1": "путь/к/изображению.jpg",
        "img_2": "data:image/svg+xml;base64,PHN2Z...",
        "text_1": "Текст с возможным \nпереносом"
    }
    }
    Важно:
    Пути к файлам указываются относительно папки resources/
    Base64 строки должны начинаться с data:image/формат;base64,
    Все изображения автоматически ресайзятся под заданные размеры паттерна
